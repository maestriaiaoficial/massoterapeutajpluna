# João Paulo Luna | Massoterapia Esportiva

Site estático feito com HTML, CSS e JavaScript.

## Arquivos principais

- `index.html`: conteúdo e estrutura das seções.
- `styles.css`: identidade visual, responsividade e animações.
- `script.js`: menu mobile, galeria ampliada, animações e formulário.
- `assets/`: logotipo, fotografias e capturas de avaliações locais.

## Visualização local

Abra esta pasta no VS Code e use a extensão Live Server para visualizar `index.html`. Também é possível abrir o arquivo diretamente no navegador.

## Agendamento e avaliações

Os botões de agendamento abrem o link oficial do WhatsApp em uma nova aba. O formulário valida os campos obrigatórios e depois abre essa conversa; o nome e o serviço precisam ser enviados manualmente no WhatsApp.

A galeria de feedbacks usa capturas de avaliações armazenadas em `assets/`. O botão do Google abre a página de avaliações em uma nova aba.

## Dependências

O site não usa backend nem bibliotecas de terceiros para funcionar. As fontes tipográficas são carregadas do Google Fonts.
